Privacy Policy

Last updated: 29 September 2026

Eimazing ("the App") is a set of personal automation tools operated by their owner to manage the owner's own content: videos on the owner's YouTube channel TikTok account, Facebook Page and Instagram account, and product pins for the owner's own Etsy shop (Eimazings). This policy explains what data the App handles. The video component is also known as "Pi Uploader".

Who this applies to

The App is used solely by its owner to access the owner's own accounts. It is not offered to the public, has no other users, does not create accounts for other users, and never acts on behalf of anyone but the owner. No visitor or customer data is collected — this website is a static page with no cookies, analytics, or tracking.

What the App accesses — Pinterest

With the owner's explicit consent through Pinterest OAuth, the App uses the official Pinterest API to:

  • create and schedule pins of the owner's own shop products on the owner's own boards (pins:write);
  • read and manage the owner's own boards (boards:read, boards:write); and
  • read basic account information needed to perform those actions (user_accounts:read).

The App never reads, stores, or interacts with content or data belonging to any other Pinterest user.

What the App accesses — Google/YouTube

With the owner's explicit consent through Google OAuth, the App uses the YouTube Data API to:

  • upload videos to the owner's YouTube channel; and
  • read basic channel information needed to perform those uploads (youtube.upload and youtube.readonly scopes).

What the App accesses — TikTok

With the owner's explicit consent through TikTok OAuth, the App uses the TikTok Content Posting API to:

  • upload the owner's own videos to the owner's own TikTok account (video.upload, and video.publish where direct posting is used); and
  • read basic profile information and the account's own posting settings needed to perform those uploads and respect the account's limits (user.info.basic).

The App never reads, stores, or interacts with content or data belonging to any other TikTok user. It does not collect information about other users' videos, comments, followers, or activity, and it does not use TikTok data for any purpose other than publishing the owner's own videos to the owner's own account.

What the App accesses — Meta (Facebook and Instagram)

With the owner's explicit consent, the App (Meta app "Eimazings Publisher") uses the official Facebook Graph API and Instagram API to:

  • publish the owner's own videos as Reels to the owner's own Facebook Page and Instagram account (pages_manage_posts, instagram_content_publish);
  • read the Page and account information needed to do so (pages_show_list, pages_read_engagement, instagram_basic, business_management); and
  • read comments left on the owner's own posts and reply to them from the owner's own Page or account (pages_read_user_content, pages_manage_engagement, instagram_manage_comments).

Comment text and the commenter's public name are processed only to write a reply to that comment. The App keeps only the ID of each comment it has answered, so it does not answer twice; it does not build profiles of commenters, and it does not access any other user's Page, account or content.

How data is stored and used

OAuth tokens granted by Pinterest, Google, TikTok and Meta are stored locally on the owner's own devices and are used only to authenticate actions on the owner's own accounts. The App does not sell, share, or transfer this data to any third party, and does not use it for advertising or profiling.

Data retention and deletion

OAuth tokens are retained only while the App is in use and can be revoked at any time by the owner: Google access at myaccount.google.com/permissions and Pinterest access in the owner's Pinterest security settings (Connected apps). TikTok access can be revoked in the TikTok app under Settings and privacy → Security and permissions → Manage app permissions. Meta access can be removed under Facebook Settings → Business integrations. See also how to request data deletion. Revoking immediately ends the App's access, and the stored tokens are deleted from the owner's devices.

Platform policies

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of the Pinterest API adheres to the Pinterest Developer Guidelines, its use of Meta APIs adheres to the Meta Platform Terms, and its use of the TikTok API adheres to the TikTok API Terms of Service and Community Guidelines, including disclosure of AI-generated content where required.
